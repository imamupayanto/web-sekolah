Prompt Arcade

Kumpulan prompt siap salin untuk membuat game HTML yang dimainkan di ponsel. Semua kontrolnya sentuhan — tap, swipe, drag, dan tombol di layar — tanpa keyboard dan tanpa mouse. Tempel ke Claude, hasilnya satu file .html yang bisa dibuka langsung di browser HP tanpa server dan tanpa internet.

Aturan 01
Jempol dulu
Semua tombol minimal 48 piksel dan diletakkan di zona bawah layar yang terjangkau ibu jari.
Aturan 02
Tanpa keyboard
Tidak ada arrow keys, WASD, atau hover. Setiap kontrol punya padanan sentuh yang jelas.
Aturan 03
Layar terkunci
Halaman tidak ikut tergeser atau ter-zoom saat dimainkan, dan menghormati area notch.
Aturan 04
Orientasi ditentukan
Setiap game punya orientasi tetap, dan menampilkan ajakan memutar HP bila salah arah.
Semua untuk HP. Setiap prompt sudah memuat syarat mobile secara eksplisit: meta viewport, penguncian scroll dan zoom, ukuran target sentuh, area aman notch, penskalaan canvas mengikuti kerapatan piksel layar, dan orientasi yang dikunci.
Empat game diganti. Typing Race, Catur, Solitaire, dan Jigsaw menuntut keyboard atau presisi mouse yang tidak nyaman di layar kecil. Penggantinya adalah Bubble Shooter, Blackjack, Reversi, dan Tebak Bendera — semuanya cukup dengan satu jempol.
Yang tidak termasuk. Multiplayer online real-time antar perangkat butuh server dan WebSocket, jadi tidak bisa lahir dari satu file statis. Versinya di sini adalah mode hotseat: beberapa pemain bergantian di satu HP.
Tips. Kalau hasil pertama kurang pas, balas dengan permintaan spesifik — misalnya "tombolnya kekecilan di HP saya" atau "pindahkan panel skor ke atas" — jangan mengulang prompt dari awal.
